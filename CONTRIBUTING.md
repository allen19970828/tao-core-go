# Contributing to tao-core-go

Thank you for your interest in contributing to `tao-core-go`! We welcome bug reports, feature requests, documentation improvements, and pull requests from developers all around the world.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
* Check existing [GitHub Issues](https://github.com/your-org/tao-core-go/issues) to ensure the bug hasn't already been reported.
* Open a new issue using the **Bug Report** template.
* Include detailed steps to reproduce, expected behavior, and system environment info.

### 2. Suggesting Features
* Open a new issue using the **Feature Request** template.
* Explain the use case, benefits, and proposed design.

### 3. Submitting Pull Requests (PRs)
1. **Fork** the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Make sure your code follows Go standard conventions (`gofmt`, `go vet`).
3. Add unit tests for your changes.
4. Ensure all tests pass:
   ```bash
   go test -v -race ./...
   ```
5. Commit your changes with clear, descriptive commit messages.
6. Open a **Pull Request** targeting the `main` branch.
